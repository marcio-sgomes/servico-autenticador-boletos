# 📄 Criando um Serviço Autenticador de Boletos

Projeto prático desenvolvido como parte dos desafios de código e formação da **DIO (Digital Innovation One)**. O objetivo principal é construir um serviço estruturado para validação e autenticação de boletos bancários, aplicando boas práticas de arquitetura, organização de namespaces, regras de negócio e validação na camada de interface (UI).

---

## 🛠️ Tecnologias e Conceitos Aplicados
* **Estruturação de Namespaces e Organização de Pastas**
* **Lógica de Negócio para Leitura e Recuperação de Código de Barras (Encode)**
* **Desenvolvimento e Validação na Camada de Interface (UI)**
* **Boas Práticas de Clean Code e Orientação a Objetos**

---

## ⚙️ Estrutura do Projeto
O projeto foi modularizado para separar as responsabilidades de negócio e interface:
1. **Estrutura do Projeto:** Definição da arquitetura base e pastas.
2. **Namespace e Configuração:** Organização do escopo do laboratório.
3. **Módulo de Código de Barras:** Lógica para processar e recuperar informações do *encode*.
4. **Camada de UI:** Implementação e validações de entrada e saída na interface do usuário.
